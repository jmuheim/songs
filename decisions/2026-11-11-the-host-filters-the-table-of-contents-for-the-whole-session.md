## 2026-11-11 — The host filters the table of contents for the whole session

**Context:** In a session the host already sets the Gastgeber checkboxes for everyone ([the host sets who is present for the whole session](2026-10-31-the-host-sets-who-is-present-for-the-whole-session.md)), but Sprache and Genre stayed each guest's own filter. On an evening that splits the room: the host narrows the list to, say, the German songs, and every guest still looks at the whole book, or at a filter of their own. The ask was plain: when the host filters, the guests get that filter, and can't filter on their own.

**Decision:** In a session a Sprache or Genre the host picks holds for everyone. Both (`filter`, `{ sprache, genre }`) ride on the host's heartbeat next to `present`, are stored with the session on every device and go along with a takeover. For the guests, a select the host has picked a value in is disabled and shows the host's value. A select the host leaves at „Alle" stays the guest's own: a guest can filter there on top of the host's choice. A later heartbeat leaves that pick alone, and it goes back to „Alle" only once the host lets go of a value it had picked there. The guest's „Zurücksetzen" clears the free selects only, and is disabled once the host has picked both. The host's „Zurücksetzen" lets go of Sprache and Genre for everyone and still leaves the Gastgeber alone. A new session starts unfiltered, and leaving one gives the filter back, nothing filtered. Outside a session nothing changes: the filter is one's own.

**Reasoning:**
- **One list for the room, where the host has a say.** A Sprache or Genre the host picked is what the evening is about, and a guest who could change it would only see songs that aren't on tonight.
- **„Alle" is no say, so the guest keeps the choice.** The first version locked both selects for the guests outright, whatever the host had picked. Then a host who filtered nothing left every guest unable to filter at all, for no reason. Locking per select keeps what the host decided and nothing more.
- **The same path as `present`.** Sprache and Genre go through the mechanism the Gastgeber checkboxes already use: the heartbeat, the stored session, the takeover, one `setSession` call in `toc-filter.js`. No second channel, no second message type.
- **Disabled, not hidden.** A greyed-out select still says what the list is filtered by. A select that vanished would leave a guest wondering why songs are missing. The dialog's info line says who chooses.
- **The host's filter is everyone's, even for a quick look-up.** The host can no longer filter privately in a session. We accepted that for one list everybody shares. The host's info line in the „Lieder von" dialog says so.
- **The Gastgeber stay the host's alone, even all ticked.** Who is here is a fact about the evening, not a filter (see the earlier entry), so all ticked is no „Alle" for a guest to narrow down. For the same reason „Zurücksetzen" doesn't touch them: resetting them along with Sprache and Genre would bring back the songs of people who went home.

Supersedes „Sprache and Genre stay each guest's own filter" in [the host sets who is present for the whole session](2026-10-31-the-host-sets-who-is-present-for-the-whole-session.md).
