## 2026-11-11 — Each reader picks a font for the titles and one for the text

**Context:** The song book was set in the night theme's Montserrat (titles) and Open Sans (everything else), with no say for the reader. Wanted: a choice of font, one for the titles and one for the content; code blocks may stay as they are.

**Decision:** ⚙️ gets two lists of radio buttons, „Titelschrift" and „Textschrift", a font to a row, each labelled with a picture of the font's name set in that font, the lists scrolling: the theme's font plus others: Playfair Display, Oswald, Pacifico, Permanent Marker, Dancing Script for the titles; Atkinson Hyperlegible, Lora, Nunito, Caveat for the text; and in both lists Antic Slab and Comic Relief (for Comic Sans). They swap the theme's `--r-heading-font` and `--r-main-font`; `--r-code-font` stays, so code blocks and chord pills keep monospace, and the dialogs keep their own font. The choice is kept per device, like the theme, and not synced over multiplex. The fonts are bundled in `style/fonts/` like the theme's own.

**Reasoning:** Two variables are all reveal.js's theme sets its type with, so the choice costs a rule per font and touches no layout code: `slide-zoom.js` already refits a slide whose size changes, and a font arriving changes it. Bundled rather than loaded from Google, for the same reason as the theme's fonts (no visitor's browser asks Google for anything); a font a page doesn't use is never downloaded, so eleven more cost the readers who keep the defaults nothing. A curated short list rather than a long one or the device's own fonts: a system font looks different on every phone. Radio buttons with a picture of each font rather than a select of names („Playfair Display (elegant)"): a name means nothing to most readers, a sample shows at a glance. Pictures, not the label set in its own font, so that opening the dialog downloads a few kilobytes of pictures rather than every font on offer; rendered by `rake fonts:samples` from the book's own fonts and CSS, so they can't drift from what a pick shows. Fifteen of them made the dialog taller than a laptop's screen. Fitting them all in at once, as tiles, shrank the pictures too small to tell the fonts apart; so each is a row large enough to read, in a list that scrolls, as tall as the screen leaves room for. On a large screen the dialog is set at 1.5rem, smaller than the other dialogs, or it still ran past a laptop's bottom edge. A shared list for both selects was rejected: a script face like Pacifico or Dancing Script is fine for a title and tiring for a whole song's lyrics; Comic Sans and Antic Slab, both asked for by name, read well in both (Antic Slab has a single weight: its bold and italics in the lyrics are the browser's own). Comic Sans itself is Microsoft's and may not be shipped, and relying on an installed copy would leave the phones without it (iOS, Android) on another font than the rest; Comic Relief is an open clone with the same metrics, Comic Neue (also open) a redrawing further from the original. The title font covers the headings only; the artist line and the next-line preview are text. The chosen fonts are a first set, to be pruned after trying them in the book; a stored choice that has since been removed falls back to the theme's font.
